# Generated examples

Everything in this folder was generated by the tool from the 12 synthetic procedures in
[`samples/tsql`](../samples/tsql) and the table definitions in [`samples/ddl`](../samples/ddl):

```bash
python -m sproc_to_lakehouse convert samples/tsql --target both --out examples
```

- [`reports/summary.md`](reports/summary.md): what converted, what needs a person, and why.
- [`reports/`](reports): one report per procedure (Markdown and JSON).
- [`dbt/`](dbt): the dbt project for the `dbt-databricks` adapter.
- [`notebooks/`](notebooks): one Databricks notebook per procedure (`.py` source format;
  import into a workspace with *Import > File*).

Nothing here is edited by hand. A test regenerates the folder and fails if it differs, so
these files always match the current code.
